# Yash Singh — Portfolio

Personal portfolio and blog built with Next.js 16, React 19, and Tailwind CSS v4.

## Setup

```bash
bun install
cp .env.local.example .env.local
```

Edit `.env.local` with your GitHub token, access password, and session secret.

## Commands

```bash
bun run dev      # Start dev server at http://localhost:3000
bun run build    # Production build
bun run lint     # ESLint
bun run typecheck
bun run check    # lint + typecheck + build
```
